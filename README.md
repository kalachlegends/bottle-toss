# Бутылки

Браузерная 3D-игра на Three.js: бросаешь стеклянные бутылки с соком в мишени на верёвках.

**Управление** — мышь или палец: захвати бутылку на полке, смахни вверх и отпусти.
Направление и скорость жеста задают бросок. Если продолжать движение вверх за светящуюся
линию над полкой, бутылка отпускается сама. Медленное перетаскивание бросок не вызывает:
бутылкой можно двигать соседей, а при резком ударе разобьются обе.

## Как устроено

- **Физика** — Rapier (WASM): выпуклые коллайдеры бутылки, CCD для бросков, мишени висят на двух
  верёвочных суставах (бифилярный подвес: маятник + восстанавливающее кручение).
- **Сила удара** — скорость сближения в точке контакта с учётом вращения, по скоростям до шага.
  Разрушение — порог по этой скорости; бутылка один раз заменяется осколками из
  `citrus-bottle-fractured.glb` в той же позе и с унаследованной скоростью.
- **Жидкость** — как в Half-Life: Alyx: фрагменты выше плоскости отбрасываются, задние грани рисуются
  как поверхность. Наклон плоскости — пружина с затуханием к «эффективной гравитации» (g − a +
  центробежная), уровень по таблице объёма, поэтому жидкость не меняет объём при наклоне.
- **Звук** — процедурный WebAudio, включается после первого касания, лимиты на одновременные голоса.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5180
npm run build        # dist/ для статического хостинга
npm run build:single # dist-single/index.html — один файл
```
